# دليل ربط تمرين نظريات القيادة بصفحة الدخول الحالية

> هذا الملف يشرح طريقتين لربط أداة التمرين (`index.html`) بصفحة التحقق من الكود الموجودة في الموقع.
> **ملاحظة مهمة:** الأداة لا تتحقق من أي كود بنفسها — الحماية كلها تتم في صفحة الدخول الحالية.

---

## الطريقة الأولى: التحويل المباشر (Redirect)

بعد أن يتحقق الخادم من صحة كود الدخول، حوّل المستخدم مباشرة إلى مسار الأداة.

### من جهة JavaScript (في صفحة الدخول):

```js
// بعد التحقق من الكود بنجاح:
window.location.href = '/tests/leadership-theories/index.html';
```

### من جهة PHP (في ملف التحقق على الخادم):

```php
<?php
// بعد التحقق من الكود:
if ($code_valid) {
    header('Location: /tests/leadership-theories/index.html');
    exit;
}
?>
```

### المميزات:
- الأبسط في التنفيذ.
- الأداة تعمل في صفحة مستقلة بعرض كامل.
- لا تتأثر بأنماط CSS الخاصة بالصفحة الأم.

### الملاحظات:
- تأكد أن مجلد `tests/leadership-theories/` متاح على الخادم.
- إن أردت منع الوصول المباشر بدون كود، أضف تحققًا على الخادم (مثل جلسة PHP) قبل تقديم الملف.

---

## الطريقة الثانية: التضمين داخل الصفحة نفسها (iframe)

بعد نجاح التحقق من الكود، أظهر `iframe` يحتوي على الأداة داخل الصفحة الحالية نفسها.

### مثال HTML:

```html
<!-- يُخفى في البداية، ويُظهر بعد نجاح التحقق -->
<div id="exercise-wrapper" style="display:none;">
  <iframe
    src="/tests/leadership-theories/index.html"
    style="width:100%; height:900px; border:0; border-radius:12px;"
    title="تمرين نظريات القيادة"
  ></iframe>
</div>
```

### مثال JavaScript (بعد التحقق):

```js
// بعد التحقق من الكود بنجاح:
document.getElementById('code-form').style.display = 'none';       // إخفاء نموذج الكود
document.getElementById('exercise-wrapper').style.display = 'block'; // إظهار التمرين
```

### المميزات:
- يبقى المستخدم في نفس الصفحة — تجربة سلسة.
- يمكن إضافة عناصر حول الـ iframe (شعار، تذييل، أزرار تنقل).

### الملاحظات:
- اضبط ارتفاع الـ iframe بما يناسب المحتوى (900px كافية عادة).
- زر الطباعة داخل الأداة يطبع محتوى الـ iframe فقط.
- إن أردت تمرير اسم المستخدم من الصفحة الأم إلى الأداة، يمكنك إضافته كمعامل في الرابط:
  ```
  src="/tests/leadership-theories/index.html?name=محمد"
  ```
  ثم قراءته داخل الأداة:
  ```js
  var params = new URLSearchParams(window.location.search);
  var serverName = params.get('name');
  if (serverName) document.getElementById('uname').value = serverName;
  ```

## ملخص

| الطريقة | التعقيد | تجربة المستخدم | التحكم في التخطيط |
|---------|---------|----------------|-------------------|
| التحويل المباشر | بسيط جداً | صفحة مستقلة | كامل |
| التضمين (iframe) | متوسط | مدمج في الصفحة | جزئي (داخل إطار) |

اختر الطريقة المناسبة حسب تصميم موقعك. كلتاهما تعملان مع نظام الحماية الحالي دون أي تعديل على الأداة نفسها.
